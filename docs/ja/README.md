# discord_forum_todo

Discord フォーラムチャンネルをタスクボードとして運用するための Bot。

- **スレッド 1 つ = タスク 1 つ**
- **アクティブタスク一覧**を Bot 専用チャンネルの 1 メッセージに集約表示
- **放置タスク**を検知して利用者ロールへ自動メンション
- **特定パターン名のチャンネル**を監視カテゴリで検知し、自動でタスク化
- **i18n 対応**（日本語 / 英語）
